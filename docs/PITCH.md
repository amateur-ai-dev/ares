# ARES — a private AI analyst for your SOC

ARES is a locally-hosted AI security assistant: it triages alerts (severity + MITRE ATT&CK + next steps), answers threat-intel questions from your own runbooks, and scans code for vulnerabilities — all on your own hardware, no data ever leaving the building.

**The problem:** SOCs drown in alerts, most false positives; analysts burn out and real threats slip through. Cloud AI could help, but sending client logs and code to a third-party API breaks data-residency and costs a fortune per seat.

**Why it wins in managed services:** client data stays provably private (a selling point cloud rivals can't match); Tier-1 clears the queue faster so you cover more clients per analyst; every shift triages with the same expert-grade reasoning; onboarding is faster; and cost is flat hardware, not ballooning per-token bills. Auditable by design — every action logged, every answer cited.

**In one line:** cloud-AI capability with on-prem privacy — analyst augmentation without the data-egress, compliance, and cost problems that keep security teams off cloud AI.
