Part one

High-Level Design

1.1 The one idea

Everything follows from a single split in responsibility.

The in-memory box is the point. Model selections never enter the claims table. A model's opinion cannot become a stored fact, because the two never share storage — a structural property, not a policy anyone has to remember.

1.2 Component view

The two double-bordered nodes are the security-critical ones: the badge firewall decides what may be called proven, and the rendering layer decides how untrusted text reaches a browser.

1.3 Deployment

Only the dotted line leaves the machine, and only when explicitly asked. Default operation is entirely local — no account, no key, no telemetry.

Part two

Low-Level Design

2.1 Data model

claim_text holds model output. It is the entire reason the hardened rendering layer in §2.6 exists.

2.2 The badge firewall

The project's central integrity control, and the one thing that had to be right.

Two layers, deliberately. A single application-level check is one refactor away from a bypass. The database triggers hold even when the Python is wrong.

The immutability trigger exists because adversarial testing found a badged claim's text could be rewritten after it was badged. A real leak, closed.

Blind adversarial testing — by a model forbidden from seeing the existing tests — found eight false-verification paths in code that had already passed a phase gate and two reviews:

  • A record claiming to be its own parent
  • Two records each claiming the other
  • Longer cycles, A→B→C→A
  • Duplicate identifiers making the true parent ambiguous
  • Whitespace accepted as a valid identifier
  • Type confusion between text and numbers
  • A boolean accepted as an event type — Python evaluates True == 1 as true

None of these appear in clean data. All of them produce a false verified from malformed input — the one outcome the design cannot tolerate.

2.3 The two shipped predicates

Both are identifier equality on the same host. That is precisely why precision on adjudicated edges sits at 100% — a floor, not an achievement.

Cut from scope: WROTE_PATH_BEFORE_EXECUTION and SAME_SESSION. They cover 5 of day 2's 23 true edges, permanently unreachable in this build. Event ID 3 carries no LogonId, which is what makes SAME_SESSION expensive.

2.4 Selection path

The prioritiser is the measured bottleneck — not the model. On day 2 all 18 in-scope true edges were enumerated, but only 6 ranked inside the top 300, giving a reachable ceiling of 33.3%. Widening the window to 1,500 moved the frontier arm from 16.7% to 55.6% with no model change and no code change. No model swap in the entire study moved a number that far.

Ranking never affects a badge. It changes only what the model is shown.

2.5 Dataset-mode enforcement

Mode is derived independently from two sources that must agree, so a wrong --mode flag cannot override the filesystem and a wrong key cannot override the run.

Demo mode produces no number at all. A caveat printed beside a figure gets cropped out of a screenshot. A figure that was never produced cannot be.

2.6 Rendering, hardened

Model rationales, log fields and filenames are all attacker-influenced and all reach a browser.

  • Autoescaping always, including in-memory templates. Jinja does not autoescape by default — a bare environment escapes nothing.
  • |safe, Markup and escape_silent raise rather than render. A template reaching for one fails instead of quietly creating an injection point.
  • StrictUndefined — a missing value is an error, not a blank.
  • CSP default-src 'none' — script has no permitted source at all. Emitted as a meta tag, because exported reports open from disk with no server headers.
  • No external assets. No CDN, no web fonts, no remote images.

Found while writing the tests for the escaping itself: autoescaping does not protect URL context. javascript:alert(1) in an href survives HTML-escaping completely intact, because nothing in it needs escaping. A scheme allowlist now collapses it — and data:, vbscript:, and control-character smuggling like java\tscript: — to a dead anchor.

At 300 edges in a single call the local model returns a well-formed empty answer — it declines rather than fails. More context did not help; recall falls monotonically as the batch grows.

Adjudication coverage: 33 of 794 badges (4.2%). The answer key describes the attack narrative, not every relation in the log, so it cannot rule on the other 761. Every precision figure here is scoped to what the key can adjudicate and claims nothing beyond it.

Not measured: day 2 on the local arm. That run was abandoned at 72% after 4 h 45 m. The local arm is proven on one incident only.
