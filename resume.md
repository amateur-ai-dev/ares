### The inversion — the single most important change (commit `3d18191`)

The pipeline had the division of labour backwards, and **the spec Claude wrote for Terra is what put it that way** — it asked the model to *discover* edges by spotting GUID matches across raw events. That is exact string matching: the task an LLM is worst at and code is perfect at. Measured: 794 edges derivable deterministically on day 1; the model found 3.

Now: **tools enumerate and verify every edge; the model selects which verified edges are the attack.** This is what §8 Phase 1 always described. Selections are held in memory and deliberately kept OUT of the claims table, so a model's opinion about relevance never shares space with a proven relation. Effect on day 1: selection recall 0% → 24.2% on a 25-edge smoke, then 66.7% on the full frontier run.

It also collapsed 25 model calls per incident into **one**. Claude's "1.5–2 hours" estimate was stale by two orders of magnitude — it came from the old design and was not recomputed when the design changed.

Pre-build / planning. ARES (formerly "Prahari") in its **own repo** (`amateur-ai-dev/ares`).

**Current framing (2026-07-28, Nithin, supersedes the wayfinder destination below):** ARES is an **MVP to prove feasibility** at a hackathon or event of that kind — **not** a production tool. Production is a later, separate track. The old destination ("a GO/NO-GO on building ARES as a real internal SOC tool that must genuinely get used") is now **downstream of the MVP, not a gate on it**.

**Shape (2026-07-28, Nithin, corrects earlier drift):** core = RAG + alert triage doing **log analysis and RCA** — reconstruct what happened, in what order, and why. Not TP/FP verdicts. Semgrep-class tools are a **verification layer inside the triage loop**. Code review is a **separate add-on** aimed at **vibe-coded automations** (AI-generated glue scripts, n8n flows, agent tooling).

**Wedge (settled by Nithin in grilling, 2026-07-28):** the **verification layer** — model proposes, deterministic tools dispose, every claim badged verified / refuted / unverifiable. Not "local" (Elastic + AI_SOC already own that), not code-scan.

**Causality rule (2026-07-28, Nithin, settled in grilling — answers Codex round-2 finding 1):** a causal edge is badged **verified** ONLY when it cites explicit relational evidence in the logs — `ProcessGuid`→`ParentProcessGuid`, shared `LogonId`, write-then-execute of the same image path, network connection bound to a process handle. **Temporal adjacency alone is never sufficient.** Codex was right that a Hayabusa timeline proves order, not causation.

**Escalation + learning loop (2026-07-28, Nithin):** an unverifiable causal claim is not a dead end. It (a) persists as a first-class DB record — needs a name, "anomaly"-flavoured but not that word, (b) raises a ticket for a human engineer — **ServiceNow is the target but the API is a LATER version**, MVP emits something local, (c) on human resolution, the relational knowledge is written back into the RAG store so future incidents resolve similar links automatically. Design brainstorm delegated to GPT/Codex per Nithin's instruction.

**Causal Gap / "Aporia" (2026-07-28, Nithin + GPT design brainstorm):** an unverifiable causal claim becomes a first-class record — `causal_gap` in the schema, **Aporia** as the UI label. Design trimmed to MVP scale: `causal_gaps` (checks stored as a JSON column) + `knowledge_items` for RAG write-back + JSON files in a local outbox. Deferred until a real need: `causal_gap_events` junction table (3+ event spans), `causal_gap_checks` as its own table, four-state `learning_eligibility`, ServiceNow adapter, predicate authoring.

**BADGE FIREWALL — non-negotiable (GPT brainstorm, adopted):** retrieved human adjudications may guide hypothesis generation and ranking, but may **NEVER** directly assign `VERIFIED`. Only fresh relational evidence in the current logs can produce a verified badge. Without this the learning loop becomes circular ("verified because a similar case was confirmed once") and one wrong analyst call compounds forever. Do not relax this.
